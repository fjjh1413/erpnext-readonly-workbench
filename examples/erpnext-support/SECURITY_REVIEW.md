# 独立安全审查与回归

审查时间：2026-10-06。范围包括新增的 `collector.py`、`runtime_tool.py`、
`models.DiagnosticResult`、`security.py`、`settings.py`、`server.py` 以及 ERP 读取适配器。
本文件记录代码审查和测试范围，不构成生产部署认证。

## 权限与数据边界

ERP 接口由服务端绑定，Agent 只有固定业务工具，不能选择 URL、SQL、Shell、凭据或其他发货单。
读取工具在调用前后及数据读取期间检查授权；环境连接、凭据别名、采集器别名、服务范围、版本或
模型授权变化会终止原任务。工作台账号与 ERP 故障操作用户分开，读取成功不证明提交权限。

运行采集器仅适用于本项目自己创建的 `holmes-erp-<12hex>` 实验环境。
它核对本地 Docker transport、项目和实验标记、完整容器 ID、记录的网络及网络成员；
未经授权的网络、容器或标签变化会拒绝采集。HTTP 只有带服务端随机 Token 的固定 `GET /snapshot`，
拒绝查询参数、其他方法、空/过短/过长 Token 和非 ASCII 认证值。
采集器不向 Agent 提供 Docker socket，固定 Redis `PING` 是唯一容器 exec，
工具没有启动、停止、删除、任意命令或 ERP 写操作。

采集器投影容器状态而不输出环境、命令和健康检查日志；应用日志固定最多 50 行、900 秒、
12,000 字符，传输字节另有限制。RuntimeTool 严格校验五个服务及其类别，拒绝额外字段，
按授权类别过滤服务并重建查询元数据；不授权 application 时不返回应用日志。
认证值、受控文件中的已知密钥以及常见密码、Token、邮箱和手机号在返回前脱敏。
标识符与业务时间不因手机号模式而被误改。
中文紧邻联系方式也会脱敏。含敏感内容的物料、仓库、单据及子行标识使用由该环境 API Secret
派生的稳定 HMAC 别名，相同标识可关联、不同标识不因通用占位符而归为一组；别名是伪名化，
不承诺匿名化。凭据轮换会改变别名。子行别名只在当前绑定发货单的最多 10 个已读取子行中解析，
不能选择其他单据或形成任意查找。旧证据只有通用脱敏占位时，规则停止确认业务关联。

证据编号由程序分配，报告结构核对编号唯一性、实际调用 ID、工具名称、执行状态、来源、查询条件、
采集/业务时间、结果片段和限制与原调用一致。模型候选只能引用存在且成功的证据，不能替代程序事实。
模型调用目标和环境模型授权显式记录；未配置、未授权或失败时标记 `rules_degraded`。

凭据别名严格受限，文件必须位于受控目录；路径解析后仍需处于目录内，并拒绝链接或目录联接。
工作台 API 使用登录、角色与环境授权、CSRF 和来源检查。任务/证据读取采用一致快照，
仍对快照中的环境重新授权。工作台记录修改与 ERP 业务写入分开。

## 审查发现及修复

|问题|修复与验证范围|
|---|---|
|流式 HTTP 单块读超时不能限制慢速滴流的累计耗时|ERP 适配器使用 `read1` 获取可读字节、剩余截止时间与调用端硬等待上限；RuntimeTool 同样有固定截止时间和硬等待。超时结果不接受迟到数据。|
|RuntimeTool 原先保留额外 payload 与未授权 query 服务元数据|增加严格 Snapshot/Service DTO 与字段限制，按授权范围重建 query。|
|仅关联证据 ID，未校验原始结果内容|报告模型加入 payload、source、query、时间及 limitations 与原调用的规范化一致性检查。|
|已有 collector.json 未校验链接、Token 和固定目标|读文件前执行受控路径检查，校验字段、大小、固定本地地址及 Token 长度。|
|非 ASCII Token 请求会令字符串 compare_digest 报错|直接拒绝不合法认证值，以权限拒绝状态返回。|
|原循环在预算耗尽/撤权时丢弃同轮已提交结果|排空当前批次实际调用记录再停止下一轮；错误记录不携带授权撤销后的业务内容。|
|Frappe 时间 JSON 不补秒零，与扩展 timedelta 字符串比较错误|仅对合法钟点做补零和精确微秒规范化；不同业务时间或非法时间仍拒绝。|
|站点时区未知、发货明细截断时可形成过度结论|未知时区停止历史规则；截断仅描述已读明细合计，数量根因保持候选并提示完整单据缺失。|
|中文紧邻手机号未脱敏，两个敏感物料编号脱敏后可能错误合并|改用 ASCII 边界，保留 UUID、调用 ID 与业务钟点；敏感业务标识以环境私钥派生稳定且不同的 HMAC 别名，通用占位证据拒绝确定关联。|
|长单词及重复密码标签可让共享正则重复扫描|共享 `docker_readonly/security.py` 的 URI/密码标签模式增加准确起始边界；4,000 字符实际旧扫描 2.274 秒，修复模式 0.0014 秒。新 12,000 字符/重复标签/中文测试包含执行时间断言。|

## 实际验证记录与限制

适配器、规则、原 Agent 循环与独立运行采集安全合同的最终回归为 **147 passed / 45.48 秒**，
有 3 个依赖弃用警告。原循环的 14 个场景仅使用 ScriptedMockLLM，原
`ToolCallingLLM.call_stream`、ToolExecutor、Tool.invoke 实际运行；这些场景不宣称模型准确率。
JUnit 记录见
[`adapter-rules-engine-runtime-verified-20261006.xml`](reports/adapter-rules-engine-runtime-verified-20261006.xml)。
编辑期间的一轮回归实际为 12 failed / 135 passed，数字转换函数的中间编辑已恢复并重新验证；
失败 JUnit `adapter-rules-engine-runtime-final-20261006.xml` 保留，未被成功结果覆盖。
共享脱敏既有测试另行定向运行，实际 **4 passed / 40.86 秒**；长文本性能、联系方式和
HTTP Timeout 新定向测试为 **3 passed / 41.16 秒**，已包含在最终 147 场景中，不重复累加。
独立真实 ERP 测试为 **12 passed / 66.24 秒**，所有请求仅 GET，没有模型和 ERP 写操作。
真实诊断记录见
[`erp-adapter-live-3fba3e081a644db3950f38e0c0c76109.json`](reports/erp-adapter-live-3fba3e081a644db3950f38e0c0c76109.json)。
其中缺日志权限、业务读取权限拒绝和受限发货单是明确失败状态，不能用成功率掩盖。
发现时间格式不一致的失败记录也保留，未用后续成功覆盖。

`test_runtime_contract.py` 是独立 Docker/HTTP 合同与安全回归，明确不连接真实 Docker、
ERP 或模型；测试 Token、作用域、固定 argv、元数据过滤、字节限制、慢源截止时间、撤权、
迟到数据、引用篡改及秘密不输出。所有 HTTP 模拟与真实 ERP 集成明确区分。

最终安全修复和报告模型集成后，真实 ERP engine 正常已过账及缺货场景复测为
**2 passed / 48.22 秒**，没有模型、没有 ERP 写入。缺货实际 6/6 工具读取成功、
诊断耗时 6.098 秒、结果 `stock_shortage`；正常实际 6/6 成功、2.041 秒、
结果 `normal/business_complete`。记录见
[`erp-adapter-live-cd618083a6a645b9aee98fd4876d98ff.json`](reports/erp-adapter-live-cd618083a6a645b9aee98fd4876d98ff.json)。
这两个场景复用了此前集成场景，不与原 12 场景重复计为新的业务覆盖。

硬等待控制的是调用端接纳结果的期限；Python 无法强行终止所有已开始的网络线程。
迟到线程只能完成已经绑定的 GET，不再发布结果，并尽力关闭连接。ERP 读取并发保有量限制为 16，
避免阻塞源无限累积读取线程。没有宣称已经验证通用客户采集器、任意 ERP 定制权限、
生产环境或真实外部模型的诊断准确率。实验人工处理由 fixture 管理员执行，Agent 仅重新读取复核。
